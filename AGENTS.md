# Repository rules

- This is a Cocos Creator 3.8.8 project targeting web-mobile.
- Never commit `dist/`; it is generated by CI.
- The AI runner is Ubuntu. Cocos Creator builds run on the `windows-2022` GitHub Actions runner; do not try to install or run Cocos Creator locally.
- There is no local test suite. Validate TypeScript by inspection and let the Windows CI build catch Cocos errors.
- Do not modify `wrangler.jsonc`, `.github/workflows/build-web-mobile.yml`, or `.github/workflows/cleanup-cloudflare-preview.yml` unless the task explicitly asks.
- Keep changes focused and do not reformat unrelated files.
- When a change affects the game client, explain what should be verified in the web-mobile build.
